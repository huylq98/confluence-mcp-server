How it works

Three steps.
Under two minutes.

01

Download & run

Download ConfluenceConnect.exe (Windows) or ConfluenceConnect.pkg (Mac) and run it. No runtime required.

02

Enter your credentials

Paste your Confluence URL and a Personal Access Token (or username and password). Click Test connection, then Save & finish.

03

Ask Claude

Fully quit Claude Desktop and reopen it. Claude can now search and read your Confluence pages.

Capabilities

What Claude
can now do.

  • Search pages with full-text or CQL queries across all spaces
  • Fetch any page by URL, title, or numeric ID
  • List all accessible Confluence spaces
  • Read page comments — inline and footer
  • List file attachments with download links
